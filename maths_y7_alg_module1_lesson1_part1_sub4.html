الإختصار

جمع الحدود المتشابهة وتبسيط التعابير الجبرية

📐

القواعد

تذكير سريع بقواعد الإختصار

▼
قاعدة 1: الحدود المتشابهة
الحدود المتشابهة هي التي تحتوي على نفس المتغير ونفس الأس. الأعداد الثابتة تعتبر متشابهة مع بعضها.
\(3x\) و \(5x\) متشابهان  |  \(2y\) و \(-4y\) متشابهان  |  \(7\) و \(2\) متشابهان
قاعدة 2: جمع الحدود المتشابهة
لجمع الحدود المتشابهة، نجمع معاملاتها (الأعداد) ونُبقي الجزء المتغير كما هو.
\(4a + 3a = 7a\)  |  \(6b - 2b = 4b\)
قاعدة 3: إزالة الأقواس المسبوقة بـ + أو -
إذا كان القوس مسبوقًا بـ + نحذف القوس مع إبقاء الإشارات داخله. إذا كان مسبوقًا بـ - نعكس إشارات جميع الحدود داخله.
\(3x + (2x - 5) = 3x + 2x - 5 = 5x - 5\)
\(4y - (2y + 3) = 4y - 2y - 3 = 2y - 3\)
قاعدة 4: الإختصار بعد النشر
إذا كان في العبارة ضرب (نشر)، ننشر أولاً ثم نجمع الحدود المتشابهة.
\(2(x + 3) + 4x = 2x + 6 + 4x = 6x + 6\)
قاعدة 5: تبسيط العبارات
الهدف من الإختصار هو كتابة العبارة في أبسط صورة ممكنة بعدد أقل من الحدود.
\(5a + 3b + 2a - b = 7a + 2b\)
✏️

تمارين

تدرب على اختصار التعابير الجبرية

▼
1 اجمع الحدود المتشابهة:
أ)\(3x + 5x =\)
ب)\(7y - 4y =\)
ج)\(2a + 3a - a =\)
💡 اجمع المعاملات واترك المتغير كما هو.
2 بسّط بإزالة الأقواس:
أ)\(5 + (2x - 3) =\)
ب)\(8 - (3y + 2) =\)
ج)\(4a + (2a - 5) - (a + 1) =\)
💡 تذكر: القوس المسبوق بـ - يقلب إشارات حدوده.
3 بسّط العبارات التالية:
أ)\(2x + 3y + 4x - y =\)
ب)\(5m - 2n + 3m + 4n =\)
ج)\(6p + 2q - 3p + q =\)
4 انشر ثم اختصر:
أ)\(2(x + 3) + 4x =\)
ب)\(3(2y - 1) - 2y =\)
ج)\(5a + 2(3a - 4) =\)
💡 وزّع أولاً ثم اجمع المتشابهات.
5 تحدٍ: بسّط العبارات الأكثر تعقيدًا:
أ)\(3x + 2(x - 1) - (x + 4) =\)
ب)\(4(2m + n) - 3(m - 2n) =\)

مسائل

مسائل تطبيقية على الإختصار

▼
🧑‍🏫 مسألة 1: عدد التلاميذ
في قسم عدد البنات \(x\) وعدد البنين \(2x + 3\). اكتب عبارة مبسطة لعدد التلاميذ الكلي.
🐔 مسألة 2: مزرعة
عند فلاح \(2x\) دجاجة و \(x + 3\) أرنبًا. اكتب عبارة مبسطة للعدد الجملي للحيوانات.
🛒 مسألة 3: مشتريات
اشترى تلميذ 3 أقلام ثمن الواحد \(x\) دينار، ودفترًا ثمنه 5 دنانير. ثم أعاد قلمين. اكتب عبارة مبسطة للمبلغ المتبقي.
✅

حلول

الحلول الكاملة لجميع التمارين والمسائل

▼

📝 حلول التمارين

التمرين 1:
أ) \(8x\)  |  ب) \(3y\)  |  ج) \(4a\)
  1. \(3x + 5x = (3+5)x = 8x\)
  2. \(7y - 4y = (7-4)y = 3y\)
  3. \(2a + 3a - a = (2+3-1)a = 4a\)
التمرين 2:
أ) \(2x + 2\)  |  ب) \(6 - 3y\)  |  ج) \(5a - 6\)
  1. \(5 + (2x - 3) = 5 + 2x - 3 = 2x + 2\)
  2. \(8 - (3y + 2) = 8 - 3y - 2 = 6 - 3y\)
  3. \(4a + (2a - 5) - (a + 1) = 4a + 2a - 5 - a - 1 = 5a - 6\)
التمرين 3:
أ) \(6x + 2y\)  |  ب) \(8m + 2n\)  |  ج) \(3p + 3q\)
  1. \(2x + 3y + 4x - y = (2+4)x + (3-1)y = 6x + 2y\)
  2. \(5m - 2n + 3m + 4n = (5+3)m + (-2+4)n = 8m + 2n\)
  3. \(6p + 2q - 3p + q = (6-3)p + (2+1)q = 3p + 3q\)
التمرين 4:
أ) \(6x + 6\)  |  ب) \(4y - 3\)  |  ج) \(11a - 8\)
  1. \(2(x+3)+4x = 2x + 6 + 4x = 6x + 6\)
  2. \(3(2y-1)-2y = 6y - 3 - 2y = 4y - 3\)
  3. \(5a + 2(3a-4) = 5a + 6a - 8 = 11a - 8\)
التمرين 5 (تحدٍ):
أ) \(4x - 6\)  |  ب) \(5m + 10n\)
  1. \(3x + 2(x-1) - (x+4) = 3x + 2x - 2 - x - 4 = 4x - 6\)
  2. \(4(2m+n) - 3(m-2n) = 8m + 4n - 3m + 6n = 5m + 10n\)

🧩 حلول المسائل

المسألة 1:
\(3x + 3\) تلميذًا
  1. \(x + (2x + 3) = x + 2x + 3 = 3x + 3\)
المسألة 2:
\(3x + 3\) حيوانًا
  1. \(2x + (x + 3) = 2x + x + 3 = 3x + 3\)
المسألة 3:
\(x + 5\) دينار
  1. \(3x + 5 - 2x = x + 5\)
